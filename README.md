Number Analyzer System 🧮

A simple Python program that takes multiple numbers as input and calculates:

- Largest number
- Sum of numbers
- Average value

🚀 Features

- Accepts multiple user inputs
- Calculates largest number
- Finds total sum
- Computes average

🛠️ Technologies Used

- Python

▶️ How to Run

1. Make sure Python is installed
2. Run the file:
   python number_analyzer_system.py

📌 Example Output

Enter numbers: 1 2 3
Largest number is: 3
Sum is: 6
Average is: 2.0
